The exact frame period is 1,001,000 / 30 = 33,366.67 µs. If you round it once to 33,367 µs and add that for every frame, each frame ends up 1/3 µs late. framecode rounds each boundary from the exact ratio, so every boundary is within 0.5 µs of the exact time at any length.
